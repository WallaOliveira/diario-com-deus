# 🚀 EXECUTAR SCHEMA NO SUPABASE

## 📋 **PASSO A PASSO:**

### **1. Acessar Supabase Dashboard:**
```
🌐 https://supabase.com/dashboard
```

### **2. Ir para SQL Editor:**
```
📁 Seu Projeto → SQL Editor (lateral esquerda)
```

### **3. Executar Schema:**
```
📄 Copiar todo o conteúdo de: supabase/schema.sql
📋 Colar no SQL Editor
▶️ Clicar em "Run"
```

### **4. Verificar Tabelas:**
```
📊 Table Editor → Verificar se aparecem:
   ✅ devotionals
   ✅ user_progress  
   ✅ user_stats
   ✅ user_achievements
   ✅ user_favorites
   ✅ trails
   ✅ user_trail_progress
```

---

## 🔧 **COMANDO RÁPIDO (Terminal):**

```bash
# Instalar Supabase CLI
npm install -g supabase

# Login
supabase login

# Link projeto
supabase link --project-ref csmoqkvdrzpgpcldaqaj

# Executar schema
supabase db reset
```
